Project 2

Fun with Filters and Frequencies

This project starts with 2D convolution written from scratch and uses it to build edge detectors (finite differences and derivative-of-Gaussian filters). The second half works in terms of frequencies: sharpening by boosting high frequencies, hybrid images that change with viewing distance, and multiresolution blending with Gaussian and Laplacian stacks.

Part 1.1

Convolutions from Scratch

I wrote two versions of 2D convolution using only NumPy. Both flip the kernel first (kernel[::-1, ::-1]) so the operation is a true convolution and not a cross-correlation. Both zero-pad the image so the output has the same size as the input ("same" mode).

Four loops

The outer two loops visit each output pixel. At that position, the inner two loops traverse the kernel and accumulate the products of its flipped weights and the corresponding pixels in the padded image. This directly implements the convolution sum.

for i in range(H):
    for j in range(W):
        curr = 0.0
        for m in range(kh):
            for n in range(kw):
                curr += flipped[m, n] * padded[i + m, j + n]
        res[i, j] = curr

Two loops

I keep the loops over output pixels, but replace the inner loops with NumPy operations: extract a window the size of the kernel, multiply corresponding entries, and sum. The calculation is unchanged; the kernel-sized work now runs in compiled array operations instead of Python loops.

for i in range(H):
    for j in range(W):
        window = padded[i:i + kh, j:j + kw]
        res[i, j] = np.sum(window * flipped)

Both versions perform O(HWkhkw) work for an H×W image and a kh×kw kernel. Using fewer Python loops reduces interpreter overhead, not the number of pixel-weight products. Both snippets use the same flipped kernel and zero-padded input described below.

For this 9×9 kernel, vectorization moves 81 multiplications and their accumulation per output pixel out of Python, giving roughly a 10× speedup in this run. SciPy also executes the traversal over output pixels in compiled code. These are single-run timings from the export script, so the exact ratios depend on the machine and input size.

Boundary handling

I use zero padding, equivalent to SciPy’s boundary="fill", fillvalue=0. Treating pixels outside the image as black can darken the border after box filtering and create artificial edges in the derivative results. In later parts, I use boundary="symm" to extend the image symmetrically and reduce these border artifacts.

Part 1.2

Finite Difference Operator

Convolving the cameraman image with Dx and Dy gives the partial derivatives ∂I/∂x and ∂I/∂y. The gradient magnitude, ‖∇I‖ = √((∂I/∂x)² + (∂I/∂y)²), measures how strongly the intensity changes at each pixel, regardless of direction. Thresholding it gives a binary edge map.

Choosing the threshold

The threshold is applied to the combined gradient magnitude, not to either directional difference alone. At 0.1, many responses from the grass remain; at 0.3, background texture is reduced further, but the coat outline and thin structures become less complete. I chose 0.2 as a compromise: the person, camera and main tripod structure remain recognizable with less background clutter. Some unwanted responses are real texture rather than sensor noise so that a magnitude threshold cannot distinguish them from object boundaries.

Part 1.3

Derivative of Gaussian (DoG) Filter

I smooth the image with a 13×13 Gaussian at σ = 2, built from a one-dimensional kernel using an outer product, then apply the same finite differences as in Part 1.2. Smoothing suppresses small-scale texture and noise, but also reduces gradient peaks, so I use a lower threshold of 0.05 rather than retaining 0.2.

Method A: blur, then differentiate

Differences from the plain finite difference

Compared with Part 1.2:

  • Much less noise. The Gaussian attenuates fine grass texture before differentiation, leaving fewer isolated responses.
  • Thicker, smoother, connected edges. Major contours appear smoother, while their responses spread across several pixels. Smoothing reduces fragmentation but does not guarantee every contour is connected.
  • Lower magnitudes. Blurring reduces the size of each step, so the useful threshold drops from 0.2 to 0.05.
  • Less fine detail. Very small structures like the distant buildings are weaker or disappear.

Method B: a single convolution with DoG filters

Convolution is associative, so (I * G) * Dx = I * (G * Dx). I build the two derivative-of-Gaussian filters once, G * Dx and G * Dy, and convolve the original image with each of them.

Verification: one DoG convolution = two-step method

I compared blurring first and then taking derivatives with applying the DoG filters directly. After excluding a seven-pixel border, the maximum differences in x, y, and gradient magnitude were all below 1.1 × 10⁻¹⁵, so the two methods gave essentially identical results. I excluded the border because the two methods handle boundary pixels differently.

Part 2.1

Image Sharpening

A Gaussian filter blurs the image. Subtracting this blurred version from the original extracts details such as edges and texture. I add these details back with weight α to sharpen the image:

sharpened = I + α(I − I * G)

To perform this in a single convolution, I multiply the Gaussian kernel by −α and add 1 + α to its center. Larger α makes details more pronounced, but can also amplify noise and create halos.

Blurred, high-frequency and sharpened versions

Varying the sharpening amount α

A small α makes the brickwork on the Taj and the kitten's fur stripes crisper. As α grows the image becomes harsh. The edges get bright and dark halos (overshoot on both sides of each step), noise and JPEG artifacts in flat regions such as the sky get amplified, and many pixels clip to pure black or white. Around α = 1 looks best for both images.

Blur, then sharpen

The re-sharpened kitten has stronger eye and stripe boundaries than the blurred input, but the fine fur and whiskers remain less distinct than in the original. Unsharp masking boosts surviving variations rather than inverting the blur, and stronger boosts can introduce halos and clipping.

Part 2.2

Hybrid Images

A hybrid image is hybrid = HighPass(I1) + LowPass(I2). I obtain the low-frequency component by Gaussian blurring I2, and the high-frequency component by subtracting a Gaussian-blurred version of I1 from I1 itself. Up close, fine details can make I1 more recognizable. From farther away (or at a smaller display size), those details become harder to resolve, allowing the broad structure of I2 to dominate.

Alignment

I align each pair using two recorded eye coordinates, then translate, scale, rotate and crop the images to a common size. This brings the main features into correspondence before adding frequency components. Two points cannot correct differences in perspective or facial proportions, so residual mismatches can still produce doubled features even when the eyes align.

Full process: Wolf (high) + Husky (low)

Fourier analysis (log magnitude)

After fftshift, low frequencies appear near the center and higher frequencies farther out. The low-pass spectrum is concentrated near the center, while the high-pass spectrum shows reduced central intensity. The hybrid combines both frequency components.

Choosing the cutoff frequencies

I used σ = 4 for the wolf’s high-pass filter and σ = 6 for the husky’s low-pass filter. These settings preserve the wolf’s fur details while keeping the husky’s broad facial structure.

Gaussian and Laplacian Stacks

Each stack contains five full-resolution, 300×300 RGB images. Starting with G0 = I, I repeatedly filter the previous level with the same 49×49 Gaussian at σ = 6, using symmetric boundary padding. The effective blur grows approximately as 6√i at level i, rather than doubling each level. This explains why later layers change gradually.

Part 2.4

Multiresolution Blending

What is mask?

The mask specifies where each image appears: white (1) selects image A, and black (0) selects image B. For the Oraple, I set the left half to 1 for the apple and the right half to 0 for the orange. After smoothing, values between 0 and 1 mix the two sources; for example, 0.7 gives 70% of A and 30% of B at that level.

Why blur the mask?

Using the same hard boundary at every level would leave an abrupt change in color and brightness. I build a Gaussian stack of the mask so each coarser level has a wider transition. Fine textures stay localized, while broad shading blends more gradually across the boundary.

Blending and reconstruction

Following the mask-based blending method, I build Laplacian stacks for A and B and a Gaussian stack for the mask. At each level i, I multiply A’s layer by the matching mask Mi, multiply B’s layer by 1 − Mi, and add the contributions:

Lblend,i = Mi · LA,i + (1 − Mi) · LB,i

I sum all blended layers, including the final low-frequency residual, to reconstruct the image. No resizing is needed because every stack level has the same dimensions. For color images, I apply the same mask weights to each RGB channel.

Vertical mask: the Oraple

The Oraple uses five levels, a 49×49 kernel and σ = 8. The left half selects the apple and the right half selects the orange. Compared with the hard cut, blending spreads the central color change, while the distinct peel textures and differing fruit contours remain visible.

Irregular masks

For Wolf + Husky, an elliptical mask selects the wolf’s central face and keeps the husky outside the ellipse. For Haerin + Cat, a circular mask selects Haerin’s face and keeps the surrounding cat. Both pairs use eye alignment from Part 2.2 and five levels with a 31×31 Gaussian at σ = 5. The additional apple/orange example uses a circle to place the apple’s center inside an orange exterior, with a 37×37 Gaussian at σ = 6.

Wolf + Husky is the most convincing blend because similar fur, tones and face shapes help hide the transition. Haerin + Cat has a more visible boundary where skin meets fur; smoothing the mask softens the edge but cannot remove that material difference. The apple/orange circle keeps apple shading in the center and orange texture around the outside, though their colors remain distinguishable. Black bands above the aligned faces come from alignment padding since the size of two pictures are different.

Part 2.4 · Bells & Whistles

Color in Blending

I blend each RGB channel separately using the same mask stack, so all channels share the same spatial transition. This avoids introducing different mask boundaries between channels, but does not guarantee artifact-free color. In grayscale, fruit identity depends mostly on shape and texture; color preserves the apple's reddish shading and the orange's yellow-orange surface. The coarse layers distribute this color difference across the transition while the fine layers retain peel texture.

Takeaway

Lesson Learned

I learned that good results depend on both the algorithm and how I prepare the images and choose parameters. Alignment and mask placement determine which features blend together, while σ controls the scale of smoothing and α controls sharpening strength. More smoothing or stronger sharpening does not always improve the result because it can remove useful details or introduce halos. I also learned to distinguish computation from visualization. My Laplacian layers initially looked almost black because of how their values were displayed, rather than an error in filtering.
